
# Perancangan UI/UX Website Pendidikan Digital

## 1. Deskripsi Proyek

Proyek ini merupakan perancangan antarmuka (UI/UX) website layanan pendidikan digital untuk Program Studi Teknik Informatika. Desain dibuat menggunakan Figma, mulai dari wireframe hingga mockup high-fidelity untuk tampilan desktop dan mobile.

## 2. Tujuan Proyek

- Membuat rancangan website pendidikan digital yang informatif dan mudah digunakan.
- Menyusun tata letak halaman sebelum masuk ke tahap pengembangan.
- Membuat mini design system agar tampilan elemen antarmuka konsisten.
- Menyesuaikan desain website untuk perangkat desktop dan mobile.
- Menampilkan identitas visual, hierarki informasi, tombol, dan card secara jelas.

## 3. Tools yang Digunakan

- Figma untuk membuat wireframe, mini design system, dan mockup.
- Desktop dan mobile frame untuk merancang tampilan pada ukuran layar yang berbeda.

## 4. Konsep Desain

Desain menggunakan gaya minimalis dan modern dengan warna utama biru dan putih. Tata letak dibuat rapi agar informasi mudah dibaca.

### Palet Warna

- Primary Blue: `#2563EB`
- Dark Navy: `#172654`
- Light Blue: `#EFF6FF`
- Background: `#F8FAFC`
- Text Primary: `#334155`
- Text Secondary: `#64748B`
- Border: `#E2E8F0`
- White: `#FFFFFF`

### Tipografi

Jenis huruf yang digunakan adalah Inter.

- H1: 40 px, Bold
- H2: 28 px, Bold
- H3: 20 px, Semibold
- Body Text: 16 px, Regular
- Label: 14 px, Medium
- Caption: 12 px, Regular

### Spacing

Sistem jarak menggunakan kelipatan 8 px, yaitu 8 px, 16 px, 24 px, 32 px, 48 px, dan 64 px.

### Komponen UI

- Tombol utama dan tombol sekunder.
- Form controls, seperti input, dropdown, textarea, dan checkbox.
- Card bidang pembelajaran dan fasilitas.
- Navigasi halaman.
- Label dan teks pendukung.

## 5. Struktur Halaman Website

### A. Beranda

Menampilkan identitas Program Studi Teknik Informatika, judul utama "Bangun Masa Depan Bersama Teknologi Digital", deskripsi program, gambar utama, serta tombol "Pelajari Program" dan "Hubungi Kami".

### B. Tentang Program

Menampilkan informasi program studi dengan judul "Mengembangkan Kompetensi Teknologi Masa Depan".

Terdapat tiga bidang pembelajaran:

1. **Web Development**  
   Mempelajari pengembangan website menggunakan HTML, CSS, JavaScript, dan framework modern.

2. **Software Development**  
   Mengembangkan kemampuan perancangan dan implementasi perangkat lunak.

3. **Data & Technology**  
   Memahami pengolahan data dan penerapan teknologi pada berbagai bidang industri.

### C. Fasilitas

Menampilkan tiga card fasilitas:

1. **Laboratorium Komputer** — mendukung kegiatan praktikum pemrograman dan pengembangan aplikasi.
2. **Ruang Pembelajaran** — digunakan untuk kegiatan kuliah dan diskusi mahasiswa.
3. **Ruang Diskusi** — digunakan untuk kerja kelompok, pengembangan proyek, dan kolaborasi.

### D. Informasi Pendaftaran

Menampilkan ajakan "Siap Memulai Perjalanan Anda?", informasi singkat mengenai program studi dan proses penerimaan mahasiswa baru, serta tombol "Hubungi Kami".

### E. Footer

Menampilkan informasi hak cipta © 2026 Program Studi Teknik Informatika dan nama Universitas ABC.

## 6. Tahapan Pengerjaan di Figma

1. **Wireframe Desktop**  
   Menyusun struktur halaman, navigasi, area gambar, tombol, dan card tanpa berfokus pada detail visual.

2. **Wireframe Mobile**  
   Menyesuaikan struktur halaman untuk layar kecil dengan mengubah layout menjadi satu kolom.

3. **Mini Design System**  
   Menentukan palet warna, tipografi, spacing, button styles, form controls, dan card styles.

4. **Mockup High-Fidelity Desktop**  
   Menerapkan warna, tipografi, gambar, tombol, card, dan detail visual pada desain desktop.

5. **Mockup High-Fidelity Mobile**  
   Menerapkan sistem desain yang sama pada tampilan mobile dengan tata letak yang disesuaikan.

## 7. Adaptasi Desktop dan Mobile

### Desktop

- Navigasi berada di bagian atas.
- Bagian hero menggunakan susunan dua kolom.
- Bidang pembelajaran dan fasilitas ditampilkan dalam tiga kolom.

### Mobile

- Konten disusun menjadi satu kolom.
- Tombol dibuat lebih lebar agar mudah digunakan.
- Gambar ditempatkan mengikuti alur konten.
- Card ditampilkan secara vertikal.

Konsistensi warna, tipografi, tombol, dan card dipertahankan pada kedua ukuran layar.
